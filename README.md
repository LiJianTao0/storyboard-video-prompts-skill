## 📖 这是什么

一个给 AI 用的 **Skill（技能包）**：把 `SKILL.md` 全文交给任意 AI，再把你的剧本发给它，它就会以导演 + 美术指导 + 摄影 + 剪辑的复合身份，按固定流程产出完整的分镜脚本包——不是一段散词，而是**参考图清单、分镜表、带 @图 引用的分段提示词**一整套，能直接粘贴进视频生成工具开跑。

适合：AI 短剧 / 漫剧创作者、短视频作者、想把小说片段可视化的人。

## 🚀 快速开始

```text
1. 复制 SKILL.md 全文，粘贴给 AI（系统提示词或对话开头）
2. 把你的剧本 / 故事 / 小说发给它
3. 按它的提问选好风格与参数 → 拿到参考图清单和分镜表
4. 复制分段提示词（带 @图 编号）到视频生成工具，上传对应参考图开跑
```

## ✨ 产出流程

| 步骤 | 做什么 | 关键点 |
| --- | --- | --- |
| 1️⃣ 风格菜单 | 先定媒介与画风 | 不开盲盒，先选再写 |
| 2️⃣ 视觉圣经 | 导演阐述 + 连续性台账 | 全片视觉统一、不穿帮 |
| 3️⃣ 参考图清单 | 五类锚图 + 逐镜指派 | 每镜用哪张图写明 |
| 4️⃣ 分镜表 | 景别、运镜、台词、字幕 | 字幕逐句写死文本与位置 |
| 5️⃣ 分段提示词 | 带 @图 编号的成品词 | 复制即可生成 |
| 6️⃣ 质检返修 | 抽帧核对、问题定级 | 单变量返修，不推倒重来 |

**五类锚图**：🧑 人物锚 · 😠 表情锚 · 🏙️ 场景锚 · 🎭 道具锚 · 🦋 双形态锚（变身前后同图）

## 🎞️ 产出长什么样

分镜表（节选示意）：

| 镜号 | 景别 / 运镜 | 画面 | 台词 / 字幕 |
| --- | --- | --- | --- |
| 1 | 中景 · 缓推 | @图3 角色靠在沙发上低头沉思，随即抬眼直视镜头 | 无台词 |
| 2 | 大特写 · 拉焦 | @图2 角色贴脸撞入前景，眼睛锁定镜头 | 无台词 |
| 3 | 全景 · 后撤升起 | 四人同框落幅，主位揭晓 | 无台词 |

分段提示词（节选示意）：

```text
极速前景拉焦：@图2 原本失焦的侧脸猛然转头，
以由下而上的大特写撞满前景，眼神冷酷蔑视、直视镜头；
@图3 被甩到远端背景虚化。冷白顶光，低饱和暗调。
```

## 🧭 核心纪律

| 纪律 | 解决什么问题 |
| --- | --- |
| 一次生成一个资产池，禁止拼跑 | 两条词拼一次生成必然串味 |
| 道具单实例锁 | 关键道具分身、被安错人 |
| 逐镜复述造型关键词 | 同一角色被生成出两个身体 |
| 多人接力亮相 | 群像出场脸漂、站位乱 |
| 招式密度与保真二选一 | 标志性招式被高密度清单吞掉 |
| 字幕逐句写死 | 只提"加字幕"永远出不来 |
| 自设图位 | 一次性配角不浪费锚图精力 |

> 全部规则来自真实生成拆解的沉淀：只收实测过的机制，未经验证的宁可撤销也不留（见文末版本记录中的 v7.4 更正）。
