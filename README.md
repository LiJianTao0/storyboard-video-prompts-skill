## 📖 这是什么

一个给 AI 用的 **Skill（技能包）**：把 `SKILL.md` 全文交给任意 AI，再把你的剧本发给它，它就会以导演 + 美术指导 + 摄影 + 剪辑的复合身份，按固定流程产出完整的分镜脚本包——不是一段散词，而是**参考图清单、分镜表、带 @图 引用的分段提示词**一整套，能直接粘贴进视频生成工具开跑。

## ✨ 产出流程

1. **风格菜单** — 先定媒介与画风，不开盲盒
2. **导演阐述与视觉圣经** — 统一全片视觉，立连续性台账
3. **参考图清单** — 五类锚图（人物 / 表情 / 场景 / 道具 / 双形态）+ 逐镜指派
4. **分镜表** — 逐镜景别、运镜、台词与字幕（逐句写死文本与位置）
5. **分段提示词** — 带 @图 编号引用，逐段可生成
6. **质检与返修** — 抽帧核对、问题单四级定级、单变量返修不推倒重来

## 🧭 核心纪律（节选）

- **一次生成一个资产池** — 两条独立脚本禁止拼跑，归属靠逐段 @图 绑定
- **道具单实例锁** — 关键道具全片只出现一份，防分身
- **多人接力亮相** — 人物静止、镜头运动，前景遮挡接力入画，主位最后揭晓
- **招式密度与保真二选一** — 要保真的标志性招式单独给足时长，不埋进高密度清单
- **字幕逐句写死** — 只提"加字幕"不生效，文本与位置逐句落字

> 全部规则来自真实生成拆解的沉淀：只收实测过的机制，未经验证的宁可撤销也不留。

## 🚀 用法

1. 打开 `SKILL.md`，全文复制
2. 粘贴给 AI 作为系统提示词，或放在对话开头
3. 把你的剧本 / 故事 / 小说发给它，按它的提问补齐风格与参数即可开工
