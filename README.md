# 分镜脚本提示词 Skill

把剧本、故事、小说、文章改编成可直接用于视频生成的专业分镜脚本。

当前版本：**v7.6**（2026-11-23）

## 文件

- `SKILL.md` — skill 主体（全部规则与流程）
- `skill.yaml` — skill 元信息

## 用法

把 `SKILL.md` 全文交给 AI（作为系统提示词或对话开头粘贴），再把你的剧本、故事或小说发给它即可。它会按固定流程产出：

1. 风格菜单 — 先定媒介与画风
2. 导演阐述与视觉圣经 — 统一全片视觉与连续性
3. 参考图清单 — 五类锚图（人物/表情/场景/道具/双形态）+ 逐镜指派
4. 分镜表 — 逐镜景别、运镜、台词与字幕（逐句写死）
5. 分段提示词 — 带 @图 编号引用，可直接粘贴进视频生成工具
6. 质检与返修 — 抽帧核对、审查问题单定级、单变量返修

## 设计要点

- 工具中立：不绑定某个视频模型；工具参数（画幅、时长）在参数卡里单独交代
- 规则全部来自实测拆解沉淀：每次吸收新机制都升版本号，版本记录在 SKILL.md 文末
- 配套纪律：一次生成一个资产池、禁止拼跑；道具单实例锁；多人接力亮相；招式密度与保真二选一
